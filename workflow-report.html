구글 스프레드시트 자동 동기화 Apps Script 설정

Google Apps Script
🎯 목표: 요약 데이터를 시트에 행 단위로 누적
스프레드시트 > 확장 프로그램 > Apps Script에 아래 함수를 등록하고 매주 실행하도록 트리거를 설정합니다.
function syncWeeklyReport(data) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('주간보고');
  var now = new Date();
  sheet.appendRow([
    Utilities.formatDate(now, 'GMT+9', 'yyyy-MM-dd HH:mm'),
    data.summary,
    data.decisions,
    data.actionItems
  ]);
  Logger.log('주간 데이터 동기화 완료: ' + now);
}
⚠️ 주의: 시트 탭 이름이 '주간보고'와 정확히 일치해야 합니다.
